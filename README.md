# Heart Disease Prediction System

Logistic Regression model that predicts heart disease from 4 inputs
(Gender, Chest pain type, Maximum heart rate, Exercise-induced angina),
trained on the UCI Heart Disease dataset (Cleveland file).

- Notebook: `Heart_Disease_Prediction.ipynb` (Steps 1-10, same structure as the Titanic notebook)
- Web app: `app.py` (Streamlit)
- Dataset: https://archive.ics.uci.edu/dataset/45/heart+disease
